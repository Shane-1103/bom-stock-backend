Commercial Update Package v1 - Backend Core

Deploy:
1. Unzip this package.
2. Upload files to GitHub backend repository.
3. Render -> Manual Deploy -> Deploy latest commit.
4. Open:
   https://bom-stock-backend.onrender.com/api/setup-db
5. Also test:
   https://bom-stock-backend.onrender.com/api/setup-db-v1

Included:
- Product Master Pro backend
- Variant Pro backend
- Warehouse Center backend
- Employees / Roles / Assignments backend
- Shipment Center backend
- Item-level partial shipment + stock deduction
- Pending Summary Pro backend
- Evidence upload backend
